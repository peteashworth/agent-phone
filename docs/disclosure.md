# Call disclosure and hard stops

_Last changed: Oct 8, 2026 (Pete, via Jasmine). Supersedes the Oct 6 wording._

## Opening line (fixed, every outbound call)

> Hi, this is Jasmine, Pete's AI assistant. This call is being recorded.

- This is the ElevenLabs agent's `first_message`. It is configured server-side and never generated by the model, so it can't be skipped or reworded.
- There is **no confirmation question**. If the person doesn't want to stay on the call, they can hang up.
- The old Oct 6 wording ("…calling on behalf of Pete. This call is being recorded. Is that okay?") is retired.

## Hard stops (server-enforced, `server/src/voice/hardStops.ts`)

These checks run on every caller turn **before** the model sees it. On a match, the server sends a short, polite closing line and ends the call (`end_call`). The model can't override this.

| Trigger | Example phrases | Action |
|---|---|---|
| Objects to talking to an AI | "I don't talk to robots", "I want a real person", "is this a bot? no thanks" | Polite close: "Understood, sorry to bother you. Goodbye." → end call |
| Objects to the recording | "don't record me", "I don't consent to recording", "stop recording" | Same polite close → end call |

- The call record stores `ended_reason = hard_stop:ai_objection | hard_stop:recording_objection` plus the triggering turn, and Jasmine gets notified in the post-call notice.
- The persona prompt also tells the model to close politely on these objections. That is a backup only; the server check is authoritative.
